# arsusha — портфолио

Одностраничный сайт-портфолио: arsusha (Арсений): пять проектов, услуги с ценами, отзывы и ответы на частые вопросы.

Сделан на чистом HTML, CSS и JavaScript. Без сборки, без фреймворков и npm — открывается двойным кликом по `index.html`.

## Структура

```
index.html      — русская версия
en/index.html   — английская версия
css/style.css   — стили и анимации (общие для обеих версий)
js/main.js      — появление блоков при прокрутке, свечение за курсором, плавные переходы
assets/         — логотип, иконки сайта, картинка для превью ссылки
```

## Как открыть локально

Скачать папку и открыть `index.html` в браузере. Всё работает без сервера.

## Что менять

Тексты, цены, отзывы и ссылки на проекты лежат прямо в `index.html`. Стили — в `css/style.css`, переменные цвета и радиусов в начале файла, в блоке `:root`.

## Использование кода

Код в этом репозитории открыт для просмотра, но не для использования. Копировать, брать в свои проекты и перепродавать нельзя — подробности в файле [LICENSE](LICENSE). Нужен похожий сайт — напишите, сделаю.
