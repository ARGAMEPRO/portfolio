# Портфолио — Арсений

Одностраничный сайт-портфолио веб-разработчика: пять проектов, услуги с ценами, отзывы и ответы на частые вопросы.

Сделан на чистом HTML, CSS и JavaScript. Без сборки, без фреймворков и npm — открывается двойным кликом по `index.html`.

## Структура

```
index.html      — вся разметка и тексты
css/style.css   — стили и анимации
js/main.js      — появление блоков при прокрутке, свечение за курсором, плавные переходы
```

## Как открыть локально

Скачать папку и открыть `index.html` в браузере. Всё работает без сервера.

## Что менять

Тексты, цены, отзывы и ссылки на проекты лежат прямо в `index.html`. Стили — в `css/style.css`, переменные цвета и радиусов в начале файла, в блоке `:root`.
